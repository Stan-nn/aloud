Aloud

A local web app that reads your documents aloud. Drop in a PDF, Word file, Markdown or pasted text; it pulls out the words and speaks them in the voice engine already built into your browser. The sentence being spoken lights up and the page follows.

Browser app Built-in voices PDF · DOCX · MD · TXT Works offline Nothing leaves your machine

Notes on the build

Two things worth agreeing on before any code is written.

Keyboard, because this is a listening app

SpacePlay / pause
← →Previous / next sentence
↑ ↓Speed up / slow down
LToggle the library
TToggle the theme

Not in these screens, on purpose

  • Word-level highlighting. Chrome fires the boundary event, Safari largely does not. Sentence-level is the reliable primitive; word-level can follow later.
  • Cloud AI voices. They would sound better and would need an API key, a server, and a bill. The trade was to stay free and offline.
  • Scanned PDFs. They contain no text to extract. The app will say so plainly rather than show an empty page. OCR is out of scope.
  • Mobile layout. Desktop browser first.
